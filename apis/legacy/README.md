# APIs legacy (reemplazadas)

Estos scripts usaban **OpenStreetMap** (Nominatim para geocoding y Overpass para POIs).
Se reemplazaron por **Google Maps Platform** (ver `apis/07_google_places.py`).

Se conservan solo como referencia histórica de cómo descubrimos las APIs gratuitas de OSM.
Ya no se usan en el flujo del agente.
